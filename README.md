# TripWeatherApp 🌦️

A Next.js application that provides a weather report for your trip based on your route and departure time.

## Features

* Enter your **start point** and **destination**
* Select the **date and time** of your trip
* Get weather information along your route
* Uses Google Maps to calculate and visualize the route
* Uses Open-Meteo for weather data

## Technologies & APIs

* **Next.js**
* **Google Maps API**
* **Google APIs**
* **Open-Meteo API**

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Note

The login and registration functionality is currently not available because it requires a configured SQL database/server.

The main trip and weather functionality can be used without the database.
